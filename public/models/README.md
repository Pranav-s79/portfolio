# Portfolio Robot Model

Model: "Low Poly Humanoid Robot" by Denys Almaral  
Source: https://sketchfab.com/3d-models/low-poly-humanoid-robot-bad584b9fbe04c85bc57438842969270  
License: Sketchfab Standard License, as reported in the downloaded GLB metadata.

## Files

- `portfolio-robot.glb` - prepared runtime asset loaded by the site.
- `portfolio-robot-report.json` - inspection report generated by `scripts/prepare_robot.mjs`.

The untouched source asset is kept at:

`assets/source/low-poly-humanoid-robot/low_poly_humanoid_robot.glb`

## Regenerate

```bash
npm run prepare:robot
```

The script preserves the source file, injects lightweight `Idle` and `Throw` GLTF animation clips into the exported GLB, and updates the report.
